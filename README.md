# 👩‍🍳 麦麦阿姨 · 你的麦当劳后勤数字员工

> 麦麦阿姨是**「班底 Zecrew」**（[北京韶聪泽明智能科技有限责任公司](https://zecrew.shaocongzeming.com)出品的 AI 助手软件）生态里的一位**数字员工**：麦当劳前台粉红衣天使姐姐的专业 + 每天安排你用餐的阿姨的懂你。本作品使用 WorkBuddy 开发，基于麦当劳官方 MCP（一切查询与操作以 MCP 官方能力为准，不编不造）——她管你的吃饭大事：盘家底、薅羊毛、点餐、算积分，越来越懂你。麦当劳程序员节创意开发大赛参赛作品，非麦当劳官方产品。

## 她的成长档案：一位数字员工在班底 Zecrew 里的一生

麦麦阿姨出生在**班底 Zecrew** 里。在那儿，造一位数字员工是这样的：

| 步骤 | 在麦麦阿姨身上 | 对应文件 |
|---|---|---|
| 🤏 **捏员工** | 定义她是谁：人设、职责、铁律 | [`EXPERT.md`](./EXPERT.md) |
| 🔧 **捏技能** | 给她配本领：一项技能就是一份可插拔的工作手册 | [`SKILL.md`](./SKILL.md) + `scripts/` |
| 🔗 **接装备** | 连接器：麦当劳官方 MCP，她的全部数据来源 | [`mcp-config.example.json`](./mcp-config.example.json) |
| 📋 **编排任务** | 教她干活的顺序：主动关怀→盘家底→薅羊毛→点餐→算积分，每条职责都是一条工作流 | SKILL.md 五大职责 |
| 🧠 **教与带** | 记忆与学习方法：上岗先读你的历史订单建立画像（记忆），上岗第一课拉实时菜单学产品结构（双菜单体系/分类逻辑/套餐可换模型）——**数据永远实时查，不缓存不背数** | 上岗建档 + SKILL.md 产品课 |
| 🎓 **带着履历导出** | 培养成熟后，她带着完整档案到任何 AI 助手上岗——WorkBuddy、Claude Code、甚至纯命令行 | **本仓库 = 她的全部履历** |

以后她要学会新本领（比如点咖啡），加一个技能包就行；换了餐厅 MCP，换根连接器就行——**员工是长期培养的，技能和装备是可插拔的**。

### 三层架构定位

```
🔌 MCP（服务池）   麦当劳官方提供，持续迭代——本作品不假设工具清单一成不变
🔧 Skill（调用层） 职责与方法——做什么、按什么原则、走什么流程
👤 专家（员工层）  人格与分寸——她是谁、怎么说话、什么绝不干
```

Skill 写的是**方法，不是能力清单**：工具以当次 `tools/list` 为准、按用途语义匹配；麦当劳 MCP 更新出新能力，按职责自然接入；用户提出新需求，先看服务池有没有——**上层不依赖下层的具体实现**，服务池怎么变，阿姨都不失业。

## 她能干什么

| 职责 | 说明 |
|---|---|
| 🪪 上岗建档 | 读你的历史订单建立**多维画像**：常用门店、消费带、品类偏好（鸡/牛/鱼）、搭配习惯（配不配饮料）、时段习惯、**备注习惯**（薯条现炸、多两袋番茄酱）——维度越多，服务越贴合 |
| ⏰ 主动关怀 | 数字员工和工具的区别：她**主动上班**。设好自动化（如每天 11:00），她来问"中午吃什么？还是点麦当劳吗？你有 2 张券今天就到期了" |
| 📊 盘家底 | 积分余额与过期预警、卡包券到期提醒、可领未领盘点 |
| 📡 薅羊毛 | 活动日历周报 + 一键领券（你点头后她才动手）；新周边/开心乐园餐新玩具附官方链接 |
| 🍔 点餐 | **知道吃什么**："老样子"10 秒复刻上一单（备注自动继承）；**不知道吃什么**：像表格筛选一样逐层收窄（品类→肉类→搭配→价格带）选出性价比最高的一款——一直买 14.5 的 1+1，绝不推七八十的套餐 |
| 🎰 算积分 | 积分商城每积分价值排行、抽奖 vs 兑换期望分析 |
| 🪪 **麦麦人格报告** | 一句话生成你的"麦麦人格"（牛肉派·夜麦星人·随心配精算师…）+ 朋友圈尺寸人格卡片图，**晒图即传播**："你的是什么派？" |

**安全铁律**：凡是动真实资产的操作（下单/领券/抽奖/兑换），阿姨只参谋不擅自动手——方案摆出来，你点头她才执行。

## 快速开始（三步，按你的工具对号入座）

### 第零步（所有人）：申请麦当劳 MCP Token

前往 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，手机号登录 → 控制台 → 激活，复制 Token（1 分钟）。

### WorkBuddy 用户（推荐）

1. 左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，粘贴下面的 JSON（替换 Token 后保存并启用）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer 你的MCP_TOKEN"
      }
    }
  }
}
```

2. 打开 [EXPERT.md](./EXPERT.md)，把「一键安装」里那段话**整段复制发给 WorkBuddy**——阿姨自动创建完成。
3. 对她说："阿姨，盘盘家底"。

### Claude Code 用户

```bash
# 1. 配连接器(Token 放环境变量,勿硬编码)
claude mcp add --transport http mcd-mcp https://mcp.mcd.cn \
  --header "Authorization: Bearer ${MCD_MCP_TOKEN}"

# 2. 装技能
git clone https://github.com/shaocongzeming/auntie-m.git ~/.claude/skills/auntie-m
```

3. 重启会话，说"麦麦体检"或"老样子"。

### 其他 MCP 客户端（Cursor / Cherry Studio / Trae / VSCode）

把 [`mcp-config.example.json`](./mcp-config.example.json) 按各自方式导入 MCP 配置，再把 SKILL.md 内容作为规则/系统指令加载。模型不挑：官方推荐 Qwen / GLM / Doubao / Kimi / DeepSeek / Gemini 均可。

### 不用 AI？命令行直接跑

```bash
export MCD_MCP_TOKEN=你的token
python3 scripts/mcd_mcp.py report          # 盘家底(只读)
python3 scripts/mcd_mcp.py profile --save  # 上岗建档
```

## 技术说明

- 业务数据全部来自**麦当劳官方 MCP Server**（除团餐/派对备用线外的全量工具编排，工具清单以实时 `tools/list` 为准，调用流程见 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md)）
- **数据边界**：订单数据覆盖麦当劳官方渠道（App/小程序点餐）；美团/饿了么等第三方平台的麦当劳订单不在 MCP 范围内——人格报告的统计口径即官方渠道订单
- `SKILL.md` 同时兼容 WorkBuddy 技能包与 Claude Code skill 格式
- 纯 Python 标准库，零依赖；无本地缓存，一切以麦当劳实时数据为准
